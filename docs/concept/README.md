# Concept: From blueprint to bold

This folder records the concept board for faizamgua.com: the design direction that was
proposed and agreed before the site was built.

| | |
| --- | --- |
| **Project** | Blueprint to B.O.L.D™ website |
| **Client** | Faiza Mgua |
| **Drawing** | Concept preview |
| **Revision** | A · 26 Nov 2026 |
| **Source** | *Blueprint to B.O.L.D™* by Faiza Mgua, 3-page PDF |
| **Status** | Agreed, with changes. See [From concept to build](07-from-concept-to-build.md). |

The board was a proposal only. Where the built site differs from it, the site and
[From concept to build](07-from-concept-to-build.md) are the current record.

## The original board

[`blueprint-to-bold-concept.html`](blueprint-to-bold-concept.html) is the board
exactly as it was presented. It's a single self-contained file with the fonts loaded
from Google Fonts and the photos embedded, so you can open it straight in a browser.
The switch in its mock-up's menu bar flips between the Blueprint and Bold states.
